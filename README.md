# Flappy Bird Game Development Workshop 🐤

Welcome to the **5-Day Game Development Workshop** where high school students learned how to build their own version of the classic **Flappy Bird** game using **HTML, CSS, and JavaScript**.

This project showcases the work completed by students during the workshop, covering everything from basic layout to game logic, animations, interactivity, and deployment using GitHub Pages.

---

## 🗓️ Workshop Overview

Over the course of five days, students were introduced to web development concepts and applied them to build a playable game. Each day focused on a specific topic:

### 🔹 Day 0 – Introduction & Setup
- Tools & Environment (VS Code, GitHub)
- What is HTML/CSS/JS?
- What makes a game fun?
- 🎥 [Intro Presentation](https://prezi.com/view/iVgPHktskjSkTOh2Pjsv/)

### 🔹 Day 1 – HTML & Layout
- Building the game interface: bird, obstacles, score
- Positioning elements with CSS
- 🎥 [Day 1 Presentation](https://prezi.com/view/XjhpMOLiwt1pxyGULOFQ/)

### 🔹 Day 2 – JavaScript Basics & Interactions
- Game loop and gravity
- Making the bird flap
- Collision detection
- 🎥 [Day 2 Presentation](https://prezi.com/view/pKwBDdMs70POotfzAZYO/)

### 🔹 Day 3 – Scoring, Obstacles & Polish
- Creating pipes and scrolling them
- Scoring system
- Visual effects and animations
- 🎥 [Day 3 Presentation](https://prezi.com/view/pKwBDdMs70POotfzAZYO/) *(Same as Day 2)*

### 🔹 Day 4 – Power-ups & Enhancements
- Difficulty levels
- Music, sound effects, and avatar upgrades
- 🎥 [Day 4 Presentation](https://prezi.com/view/VR4i9s9IEx5c2ZgtPOWl/)

### 🔹 Day 5 – Final Touches & Publishing
- Adding a favicon

- 🎥 [Day 5 Presentation](https://prezi.com/view/sZtid7HW3vJWrgZ2L3m8/)

## 🚀 Deployment Instructions

Each student has deployed their game using GitHub Actions and GitHub Pages:

1. Go to **Settings > Pages** in your repository.
2. Select **Deploy from GitHub Actions** as the source.
3. Your game will be available at:
https://<your-username>.github.io/<repository-name>/

## 🏆 Final Competition

After the workshop, students scanned a QR code to play and vote for their favorite games. The winner received a prize based on creativity, design, and gameplay.
